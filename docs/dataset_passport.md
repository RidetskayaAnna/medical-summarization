
# Паспорт набора данных

## 1. Общая информация

**Название:** Medical Summarization Dataset

**Назначение:** разработка и оценка методов автоматической суммаризации медицинских историй болезни для передачи информации между врачами.

**Тип данных:** синтетические текстовые медицинские данные.

**Формат:** CSV.

**Количество записей:** 333.

**Количество признаков:** 3.

## 2. Структура набора данных

Набор данных содержит следующие поля:

| Поле | Описание |
|---|---|
| `id` | Идентификатор медицинской истории |
| `full_history` | Полный текст медицинской истории |
| `reference_summary` | Эталонное краткое изложение медицинской истории |

Каждой медицинской истории соответствует эталонное резюме, используемое для оценки качества автоматической суммаризации.

## 3. Источник и особенности данных

Набор данных представлен в виде синтетических медицинских историй и эталонных резюме.

Данные используются исключительно в исследовательских и учебных целях. Они не предназначены для постановки диагнозов, выбора лечения или принятия реальных клинических решений.

Синтетический характер данных ограничивает возможность переноса результатов экспериментов на реальные медицинские документы.

## 4. Результаты проверки качества данных

В ходе первичного аудита и разведочного анализа получены следующие результаты:

| Показатель | Значение |
|---|---:|
| Количество записей | 333 |
| Количество уникальных ID | 331 |
| Количество уникальных историй | 332 |
| Количество пропусков | 0 |
| Количество полных дубликатов строк | 0 |
| Количество повторяющихся историй | 1 |

Обнаружены повторяющиеся идентификаторы. Также выявлена одна повторяющаяся медицинская история, представлена в двух записях с различающимися эталонными резюме.

При ручной проверке выборки обнаружены отдельные случаи потери клинически значимой информации в эталонных резюме, а также содержательная аномалия в одной из медицинских историй.

| Показатель | Значение |

## 6. Разбиение набора данных

Для проведения экспериментов набор данных разделён на три подмножества:

| Подмножество | Количество записей | Доля |
|---|---:|---:|
| Train | 233 | 69,97% |
| Validation | 50 | 15,02% |
| Test | 50 | 15,02% |
| Всего | 333 | 100% |

При разбиении использовано фиксированное значение `random_state = 42`.

Одинаковые медицинские истории не распределялись между разными подмножествами, что позволяет избежать утечки данных при обучении и оценке методов суммаризации.

Файлы разбиения:
- `data/processed/train.csv`
- `data/processed/validation.csv`
- `data/processed/test.csv`

## 7. Ограничения набора данных

1. Небольшой объём набора данных — 333 записи.
2. Синтетический характер медицинских историй.
3. Наличие повторяющихся идентификаторов.
4. Наличие повторяющейся медицинской истории.
5. Возможная неполнота отдельных эталонных резюме.
6. Невозможность считать результаты экспериментов доказательством клинической пригодности системы.

## 8. Визуализация

В рамках разведочного анализа подготовлены графики:

- Распределение длины медицинских историй.
- Распределение длины эталонных резюме.
- Сравнение длины исходных историй и резюме.

Графики расположены в каталоге `reports/eda/`.

## 9. Вывод

Проведённый анализ показал, что набор данных содержит 333 медицинские истории с соответствующими эталонными резюме. Пропущенные значения и полные дубликаты строк отсутствуют. Выявлены повторяющиеся идентификаторы и одна повторяющаяся история.

Данные разделены на обучающую, валидационную и тестовую выборки в пропорции 70/15/15 с контролем пересечения одинаковых историй.

Набор данных может использоваться для экспериментального сравнения методов автоматической суммаризации медицинских текстов с учётом выявленных ограничений.
