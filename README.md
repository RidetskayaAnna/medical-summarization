
# Суммаризация историй болезни для передачи между врачами

Курсовая работа по дисциплине «Прикладные интеллектуальные системы».

## О проекте

Проект представляет собой интеллектуальную систему суммаризации медицинских историй болезни. Система формирует краткие резюме исходных текстов, позволяя выделить основную информацию для её последующей передачи между врачами.

В проекте используются три метода суммаризации: Extractive Baseline, Zero-shot и Few-shot.

## Основные задачи

- Подготовка и анализ набора синтетических историй болезни.
- Разработка базового метода суммаризации (Extractive Baseline).
- Реализация суммаризации с использованием Zero-shot prompting.
- Реализация суммаризации с использованием Few-shot prompting.
- Оценка и сравнение качества полученных резюме.
- Разработка API для взаимодействия с системой.
- Разработка пользовательского веб-интерфейса.

## Методы суммаризации

- **Extractive Baseline** — извлечение наиболее значимых предложений из исходной истории болезни.
- **Zero-shot** — генерация резюме языковой моделью без предоставления примеров.
- **Few-shot** — генерация резюме языковой моделью с использованием примеров.

## Установка и настройка

### 1. Клонирование репозитория

```bash
git clone <URL-репозитория>
cd medical-summarization
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Активация в Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка API-ключа

Для работы методов Zero-shot и Few-shot используется DeepSeek через API сервиса AIAI.

В корневой папке проекта необходимо создать файл `.env` и добавить в него:

```ini
AIAI_API_KEY=your_api_key
```

Вместо `your_api_key` укажите собственный API-ключ.

Адрес API: `https://api.aiai.by/v1`.

**Важно:** не публикуйте API-ключ и не добавляйте файл `.env` в Git. Он уже исключён из отслеживания через `.gitignore`.

## Запуск приложения

Приложение состоит из двух компонентов: серверной части FastAPI и пользовательского интерфейса Streamlit.

Для полноценной работы необходимо запустить оба компонента в отдельных терминалах.

### 1. Запуск API

Откройте первый терминал, активируйте виртуальное окружение и перейдите в папку `src`:

```powershell
cd src
```

Запустите сервер:

```bash
uvicorn api.main:app --reload
```

После запуска API будет доступно по адресам:

- API: [http://127.0.0.1:8000](http://127.0.0.1:8000)
- Документация API: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- Проверка состояния: [http://127.0.0.1:8000/health](http://127.0.0.1:8000/health)

### 2. Запуск пользовательского интерфейса

Откройте второй терминал. Перейдите в корневую папку проекта и активируйте виртуальное окружение:

```powershell
.venv\Scripts\Activate.ps1
```

Запустите Streamlit:

```bash
streamlit run src/ui/app.py
```

После запуска интерфейс откроется в браузере по адресу:

[http://localhost:8501](http://localhost:8501)

## Использование API

Основной endpoint для суммаризации:

`POST /summarize`

Пример тела запроса:

```json
{
  "text": "Текст медицинской истории болезни",
  "method": "all"
}
```

Доступные значения параметра `method`:

- `baseline`
- `zero_shot`
- `few_shot`
- `all`

Для проверки доступности сервера предусмотрен endpoint:

`GET /health`

Полная интерактивная документация API доступна по адресу `http://127.0.0.1:8000/docs`.
